# CodeAlpha_Iris_Classification
This repository contains a Machine Learning project focused on the classic Iris Flower classification problem. Using the physical dimensions of sepal and petal leaves, the model predicts whether a flower belongs to the Setosa, Versicolor, or Virginica species.

# Key Features
Comprehensive EDA: Detailed visualization of feature distributions and correlations.
Pre-processing: Data scaling and automated splitting for robust training.
Predictive Modeling: Implementation of the K-Nearest Neighbors (KNN) classifier.
Performance Metrics: High accuracy achieved through hyperparameter tuning.
